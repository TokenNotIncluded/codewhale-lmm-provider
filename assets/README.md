# Plugin artwork

`icon.svg` is the editable LMM for Codewhale mark. The four ribbon paths come
unchanged from the parent project's
[`logo-geometry.json`](https://github.com/TokenNotIncluded/lmm-api/blob/ebabe6fcc89dfbfb049bd562666b17f699d90a38/.github/assets/logo-geometry.json),
an SVG adaptation of the owner's supplied LMM master. The whale-tail detail
identifies this companion adapter without using Codewhale's trademark artwork.

The asset is self-contained, uses no fonts or network resources, and ships in
the npm package. Codewhale's documented plugin manifest has no custom icon
entry; this mark is used in package documentation rather than advertised as a
native model-picker icon.
